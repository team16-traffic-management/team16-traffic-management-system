# Code Coverage Report

Status: Automated final-source coverage is generated by GitHub Actions; attach the latest successful coverage artifact before submission.

## Measurement scope
- Coverage job: coverage in .github/workflows/ci-cd.yml.
- Script: scripts/run_coverage.sh.
- Compiler: Ubuntu runner GCC (version recorded in the workflow log).
- Instrumentation: GCC --coverage at -O0 -g.
- Included production translation units: every .cpp under src/ and vehicle/, including src/main.cpp.
- Excluded: tests/test_traffic_management.cpp (test harness, not product code) and header-only code.
- Executed inputs: consolidated automated test executable plus baseline, zero-value and high-load app fixtures; invalid and corrupted fixtures are expected to exit non-zero.

## Results
Copy the exact line coverage percentage and executable-line count from the latest successful CI coverage artifact. Do not substitute the historical 95.61% result: that older figure covered only tests/test_traffic_management.cpp and vehicle/VehicleGenerator.cpp.

The workflow uploads index.html (detailed source line/branch report) and coverage.xml (machine-readable Cobertura report).

## Interpretation and limitations
Coverage reports describe execution of instrumented production code, not requirement acceptance. They do not establish that all 66 Test Plan cases passed. Review branch outcomes as well as line execution, and retain the exact commit SHA and workflow run link with the artifact.
