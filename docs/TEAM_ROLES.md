# Team Roles and Responsibilities

Project: Traffic Management System — Team 16
Course: Software Engineering mini-project

## Team allocation

| Project role | Team member | Main responsibility | Evidence expected |
|---|---|---|---|
| Developer | Khushi | Implement assigned features, maintain modular source code, integrate modules, fix defects and support the build/CI process. | Commits, pull requests, implementation notes and linked tests. |
| Tester | Tejas Shetty | Prepare and execute test cases against the requirements, record actual results, verify fixes and report reproducible defects. | Test register, unit/system test reports, execution logs and retest evidence. |
| QA / Documentation | Tarun Gowda | Review requirement traceability, check documentation consistency, monitor quality criteria and maintain the submission checklist. | Traceability review, documentation review, QA findings and release checklist. |

## Working agreement

1. Every implementation change should reference the requirement or issue it addresses.
2. Tests should be run against the exact commit being reported.
3. The tester should record the command, environment, expected result, actual result and outcome for each executed test.
4. QA should verify that reported results are supported by evidence and that documentation matches the implementation.
5. Defects should include reproduction steps, expected result, actual result and environment.
6. Only the person who performed a review or test should record the corresponding approval or conclusion.
7. Update this allocation if the team agrees to change responsibilities.
