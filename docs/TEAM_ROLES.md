## Working agreement
1. Every implementation change should reference the requirement or issue it addresses.
2. Tests should be run against the exact commit being reported.
3. A developer's successful local run does not replace independent testing where the test plan requires it.
4. Defects should include reproduction steps, expected result, actual result and environment.
5. Only the person who performed a review or test should record the corresponding approval or conclusion.
6. Keep role allocation consistent with the actual team agreement and course instructions.
