# Team Roles and Responsibilities

Project: Traffic Management System — Team 16  
Course: Software Engineering mini-project

## Team allocation
| Role | Team member | Main responsibility | Evidence expected |
|---|---|---|---|
| Developer | Khushi Gupta | Implement assigned features, maintain modular source, integrate modules and fix defects. | Commits, pull requests, implementation notes and linked tests. |
| Tester / QA execution | Tejas Shetty | Prepare and execute requirement-based tests, record actual results, verify fixes, review PR behavior and report reproducible defects. | Test register, test reports, execution logs and retest evidence. |
| Jira / CI-CD coordination | Tarun Gowda | Maintain Jira workflow and coordinate CI/CD pipeline and project tracking. | Jira status, workflow/pipeline evidence and coordination records. |

## Working agreement
1. Every implementation change should reference the requirement or issue it addresses.
2. Tests should be run against the exact commit being reported.
3. The tester records command, environment, expected result, actual result and outcome for each executed test.
4. Jira and CI/CD coordination remains with Tarun; feature implementation remains with Khushi.
5. Defects should include reproduction steps, expected result, actual result and environment.
6. Only the person who performed a review or test should record the corresponding approval or conclusion.
7. Update this allocation if the team agrees to change responsibilities.
